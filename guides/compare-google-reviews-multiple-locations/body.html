How to compare Google reviews across multiple locations

If you run more than one location, Google shows each one's reviews separately, so it's hard to tell which branch is slipping. Putting every location's reviews into one spreadsheet answers questions like "which store gets the most complaints about wait times?" in a few minutes.

1. Export each location

  1. Add Maps Reviews Exporter to Chrome. It's free and needs no account.
  2. Open the first location on Google Maps, click the extension, set the sort to Newest and click Collect reviews, then Export CSV.
  3. Open the next location and repeat. Collecting a new place starts a fresh list, so nothing from the previous location gets mixed in.

Every row of the export includes the place name and address (columns A and B), so you can combine the files and still tell the locations apart.

2. Combine them into one sheet

In Google Sheets, import the first CSV, then for each other file use File → Import → Append to current sheet. In Excel, paste each file's rows under the last one, leaving out the repeated header row. You now have one table with every review from every location.

3. Build the comparison with one pivot table

Insert a pivot table with place_address (column B) as rows, then add these values:

  • Average of rating (column I): the headline score per location.
  • Count of rating: review volume, a rough proxy for how busy each location is.
  • Count of owner_response (column Q): divide it by the review count to get each location's reply rate.

Add a filter on date_estimated (column K) for the last 90 days to see current performance instead of all-time history.

4. Find which location has which problem

Add a helper column that flags a theme, for example =IF(ISNUMBER(SEARCH("wait",M2)),1,0) for reviews mentioning a wait (column M is the review text). Add that column to the pivot as a sum, and you'll see which branch the complaint actually comes from. Repeat for themes like "rude", "dirty", "price" or "parking".

5. Share it with managers

A one-page table of rating, volume, reply rate and top complaint per location makes a simple monthly scorecard. Re-run the exports each month with the sort set to Newest and compare.
